A · Heroic as banner

  • Cinematic: the render gets full center-stage width, like a film frame above the story.
  • Wide aspect suits locations and establishing shots; tight portrait crops of a single NPC waste width.
  • Costs vertical space: the log starts lower, so less story is visible per screen.
  • Spatial surface lives in the rail at fixed size — the map never competes with the heroic.

B · Heroic as tall companion

  • Portrait aspect flatters characters — the most common heroic subject in conversation-heavy play.
  • Log keeps full height; picture and prose sit side by side like a book spread.
  • In combat the heroic yields: it shrinks and the map slides in beneath it, both visible in one column.
  • Narrowest log column of the three — long GM paragraphs wrap harder.

C · Heroic as supporting rail

  • Closest to the current visualizer position — least layout disruption, prose stays dominant.
  • Heroic reads as a portrait card, not a set piece; less impact when a new location lands.
  • Rail stacks heroic over situation/map, so both surfaces are always co-visible at small size.
  • Smallest map of the three — fine for token positions, cramped for larger encounters.

D · Dynamic spotlight (response to 2026-07-03 feedback)

  • Base layout is B improved per feedback: one info rail (character + situation stacked), log and tall heroic share the main field. No wasted second rail.
  • Any surface spotlights on click — heroic zooms for a great render, map grows for tactics, log maximizes for reading, character expands to a full sheet (attributes, inventory, abilities appear only when focused).
  • Everything demoted stays visible in the rail — no modal, no lost context. Esc restores.
  • Pure frontend (CSS grid area swaps); the engine already emits the positional signal, so combat could later auto-suggest the map spotlight.

Shared rules in all layouts (per plan.md): the heroic persists until the game moves past it — new location, or an NPC takes prominence; the engine owns current_heroic. The situation panel is the same surface at two fidelities: scene-grounding text by default, tactical map + tokens only when position matters. Resolution stays narrative — tokens inform theater-of-mind play.
