# Cross-genre archetype option atlas and coverage audit

**Status:** owner-requested design audit; no roster, rules package, or implementation is approved by this document  
**Date:** 2026-08-02  
**Scope:** test the class taxonomy independently of the three frozen rules-system variants in `rules-system-variants.md`

## Bottom line

The current nine-archetype roster is not broad enough to approve. It has two clear missing mechanical homes—companion-centered characters and sequence-based martial adepts—and it hides a third plausible home for characters whose main play is enabling allies. It also treats Intruder as universally viable even though that loop needs protected systems to be common.

This audit therefore carries **ten universal roster candidates**, **two conditional candidates**, and **one campaign module** forward for comparison:

- Universal candidates: Armsmaster, Berserker, Adept, Opportunist, Arcanist, Channeler, Oathbound, Shifter, Maker, Bonded.
- Conditional candidates: Intruder, when the campaign guarantees protected systems; Catalyst, when it guarantees allied actors.
- Campaign module: Rider, when vehicles or mounts are a first-class scene system.

Those are options, not a ruling that the answer is twelve or thirteen classes. Every candidate below has a concrete repeated loop so the owner can see whether the distinction is mechanically real. Jobs, ranks, tactical roles, wealth, and ordinary learned capabilities remain outside the class roster.

## 1. How to read the taxonomy

Character creation remains:

1. choose a **mechanical archetype**;
2. choose one authored **genre class** from that archetype's cell in the campaign catalog;
3. choose training, background, standing/means, assets, and identity;
4. confirm the complete legal mechanic card.

The two names in each genre cell are real authored class packages, not AI aliases. They implement the two branches shown in §3. A chosen genre class remains the character's class; moving campaigns does not automatically rename it from one matrix cell to another. Campaign-local ability wording can vary only under the separately approved portability contract.

An archetype is admitted only when it owns all of these:

- a decision that recurs during ordinary play;
- state or permissions that a common skill, feat, item, role, or asset does not grant;
- a progression track that deepens that loop;
- an always-available floor when its ideal setup is absent;
- a clean boundary against multiclassing and one-level dips;
- an honest mapping across the supported genre catalogs.

An example character is a **touchstone for the dominant loop**, not a claim that every version of that character has only one class. Batman, Geralt, Iron Man, Yuna, and similar hybrid characters are useful precisely because different builds of them land differently.

## 3. Candidate mechanics

### 3.1 Status meanings

- **Universal candidate:** has a portable loop and a playable floor on paper. It still needs numerical balance and playtesting.
- **Conditional candidate:** has a coherent loop only when campaign creation guarantees its target subsystem. The UI must not offer it in a campaign that lacks that guarantee.
- **Campaign module:** changes scene scale or party assumptions enough that the whole campaign must opt into supporting rules.

### 3.2 Mechanical identity summary

| Archetype | Status | Exclusive repeated loop | Branch A | Branch B | Main collision to test |
|---|---|---|---|---|---|
| **Armsmaster** | Universal | Choose a weapon Form each turn; its attack rider and one prepared Counter replace the prior Form | **Discipline:** deeper forms, guards, counters | **Pursuit:** quarry, movement, ranged/skirmish forms | Adept if forms become sequences rather than free choices |
| **Berserker** | Universal | Voluntarily raise Exposure to unlock stronger riders while making retaliation or harm more dangerous | **Fury:** burst and self-exposure | **Endurance:** convert endured harm into staying power/retaliation | Ordinary high-HP fighter if Exposure has no consequential tradeoff |
| **Adept** | Universal candidate newly exposed by audit | Techniques print entry and exit stances; chaining legal techniques reaches finishers, which reset the chain | **Flow:** longer/faster chains and repositioning | **Stillness:** holds or redirects stance for counters/control | Armsmaster if order of techniques does not matter |
| **Opportunist** | Universal | Create one rules-defined Opening, exploit it once for a precision effect or mastered stunt, then build the next | **Opening:** conflict setup/payoff | **Mastery:** expertise, preparation, reliable noncombat stunts | Intruder if Access is merely a renamed Opening |
| **Intruder** | Conditional | Probe a protected system, gain and spend Access on exact permissions while Alert advances toward lockdown | **Ghost:** entry, concealment, extraction | **Breaker:** locks, wards, devices, networks | Opportunist/Maker, and blank scenes with no protected system |
| **Arcanist** | Universal | Prepare a limited immediate loadout from a broad learned catalog; decide which exact ranked effect is worth its package-specific use | **Formula:** broader immediate effects | **Ritual:** slower, larger workings with requirements | Channeler if preparation ceases to constrain choices |
| **Channeler** | Universal | Use a narrow known repertoire without preparation; choose whether a printed overreach is worth its recovery consequence | **Restoration:** prevent, cleanse, restore | **Manifestation:** force, influence, phenomena | Arcanist if it acquires broad on-demand catalog access |
| **Oathbound** | Universal | Choose one engine-authored declaration card and bind its exact ward, objective, zone, or foe; interdictions and marks work only through that binding | **Aegis:** protect a named ally/place | **Judgment:** pursue a named foe/wrong | Defender role or Leadership skill if target binding never constrains play |
| **Shifter** | Universal | Switch one active authored profile; movement, defenses, senses, and available powers replace rather than stack | **Predator:** fewer combat-specialized profiles | **Adaptive:** broader utility profiles and quicker switches | Adept/Maker if profiles change only a cosmetic stance or equipment |

### 3.3 Minimum playable mechanic cards

These cards define the smallest mechanic that must survive in all three rules variants. Commitment, Slots and rests, and Cadence may price limited abilities differently; they may not replace the loop with a renamed generic Power pool.

#### Armsmaster

- **Tracked state:** one active Form and at most one armed Counter.
- **Ordinary turn:** choose or keep a Form, take a weapon action using its printed rider, then arm or preserve the Counter printed by that Form. Choosing another Form replaces both, so the class is choosing a tactical posture rather than stacking bonuses.
- **Progression:** unlocks new Forms, stronger branch-specific riders, and counters with harder positioning requirements. Weapon proficiency alone never grants Forms.
- **Floor:** every Form includes a legal Standard-attack line. A fight without quarry, cover, or special terrain still leaves a complete turn.

#### Berserker

- **Tracked state:** Exposure on a short ordered track. Exposure is danger, not mana: raising it opens printed techniques and also makes at least one defense, harm result, or forced-position consequence worse.
- **Ordinary turn:** stay safe and use the baseline attack, or raise Exposure before a technique to add its printed rider. Fury cashes danger into immediate output; Endurance waits for actual harm and turns survival into retaliation or recovery.
- **Progression:** unlocks additional effects at existing Exposure, controlled ways to lower it, and branch benefits that never erase the risk.
- **Floor:** a Hardy standard attack and Endure action remain legal at zero Exposure.

#### Adept

- **Tracked state:** current technique stance and the visible next legal links. There is no point pool.
- **Ordinary turn:** use an opener from any state, follow its printed exit into a Flow technique, then use a legal finisher that resets the chain. Stillness can hold or redirect one transition for a counter/control choice; Flow rewards completing longer chains and moving through the scene.
- **Progression:** adds alternate links, new finishers, and authored branch exceptions. Buying Melee or unarmed proficiency does not grant a form chain.
- **Floor:** at least one opener is always legal and has a Standard-action value. Losing a chain costs position in the sequence, not the ability to act.

#### Opportunist

- **Tracked state:** at most one Opening on a target or obstacle and, for Mastery, a small authored list of mastered applications.
- **Ordinary turn:** satisfy a visible setup—feint, concealment, leverage, distraction, evidence, or an ally's authored condition—to create an Opening; consume it once for precision harm, movement, disarm, disclosure, or another fixed effect. The payoff cannot repeat until a new setup occurs.
- **Progression:** adds setup routes and payoff choices rather than simply multiplying damage. Mastery makes selected common-skill stunts deterministic within printed limits.
- **Floor:** every build can create a modest Opening without relying on another class or a special scene feature.

#### Intruder

- **Tracked state:** an engine-authored protected-system map, Access, and an Alert/lockdown clock. “System” can be a network, ward lattice, secure building, social security cordon, machine, or trap complex, but it must have real nodes and permissions.
- **Ordinary turn:** Probe to reveal a node or defense; Breach a revealed node to gain Access; spend Access for an exact permission such as enter, extract, disable, redirect, or conceal. Failed or noisy actions advance Alert. Full Alert changes or closes routes instead of merely dealing damage.
- **Progression:** adds programs/tools, simultaneous Access capacity, and bounded ways to suppress Alert. Systems and Stealth skills let anyone attempt ordinary tasks but do not grant Intruder programs or permission spends.
- **Floor and gate:** a campaign must guarantee recurring protected systems and provide a small local target in ordinary scenes. Without that campaign contract, Intruder is not offered; pretending every creature is a “system” would collapse it into Opportunist.

#### Arcanist

- **Tracked state:** learned catalog, prepared immediate loadout, ritual requirements, and the selected package's exact use cadence.
- **Ordinary turn:** prepare outside immediate danger, then choose whether to use one of a limited set of exact ranked effects. An unprepared learned effect cannot become an immediate cast through persuasive prose; it is available only through an authored ritual route if one exists.
- **Progression:** expands rank access, learned breadth, preparation capacity, and branch-specific formula or ritual permissions.
- **Floor:** a small rank-0 effect and Lore action remain available after limited castings are unavailable.

#### Channeler

- **Tracked state:** narrow known repertoire and the selected package's explicit recovery pressure. Each effect's overreach line states its consequence; the UI never asks the player to pour arbitrary points into it.
- **Ordinary turn:** choose any known legal effect at its base line, or take its printed overreach for the printed extra result and consequence. Restoration changes the repertoire toward prevention/cleansing; Manifestation changes it toward force, influence, and phenomena.
- **Progression:** learns a small number of new effects and improves specific overreach lines. It never gains Arcanist's broad prepared catalog.
- **Floor:** one basic manifestation or restorative support action stays available without overreach.

#### Oathbound

- **Tracked state:** one engine-known declaration ID and its exact bound entity, objective, zone, or foe. The declaration is never interpreted from free prose.
- **Ordinary turn:** choose or keep the declaration card, then use its reactions, marks, movement, and attacks only through the bound target and printed distance/trigger rules. Leaving a required range ends an Aegis; attacking another target receives no Judgment benefit; changing the binding costs an authored action.
- **Progression:** adds declaration cards, stronger interdictions, and branch-specific consequences. Leadership can help command allies but never grants these binding reactions.
- **Floor:** a legal card can bind self, an ally, an objective, a zone, or the immediate threat, so the chassis is not waiting for a garrison or institutional order.

#### Shifter

- **Tracked state:** exactly one active profile, with the complete replaced fields shown together.
- **Ordinary turn:** remain in the profile that fits the problem or pay the authored switch action/cadence to replace it. Predator commits harder to a smaller set; Adaptive changes more often among broader movement, sense, defense, and utility packages.
- **Progression:** unlocks profiles and profile-specific upgrades. It never lets the player cherry-pick one defense from one profile and one power from another.
- **Floor:** the base profile is fully playable and at least one starting alternate profile is usable without a special environment.

#### Maker

- **Tracked state:** prepared device cards and a strict active-installation limit. Devices have exact operations; “I build something” prose never creates a mechanic.
- **Ordinary turn:** deploy or trigger a prepared device, decide which existing installation to retire when at the limit, and recover/reconfigure only at the package's stated opportunity. Kit favors portable and single-use answers; Forge favors persistent modules, barriers, and emplacements.
- **Progression:** adds catalog rank, preparation capacity, and module/installation sophistication. Craft skill repairs ordinary gear but does not mint class devices.
- **Floor:** every loadout includes at least one reusable field tool worth a standard action, preventing an empty turn after consumables are gone.

#### Bonded

- **Tracked state:** one active companion profile, separate positions and conditions, and a shared Main action. The companion is a class-owned entity record, not unbounded GM favor.
- **Ordinary turn:** both bodies may reposition under the exact movement rule, but only the character or companion takes the shared Main. Coordinated abilities require stated relative positions or a setup from the other body. Partner advances one persistent companion; Caller switches among a bounded roster and never fields an uncontrolled army.
- **Progression:** grants companion forms, commands, coordination reactions, and survivability. A companion cannot permanently die from one unlucky scene unless the broader defeat rules allow the same player choice as for the character.
- **Floor:** the active companion always has a basic Main action, including in a sealed dungeon or asset-poor campaign. A corporation, follower squad, or ordinary pet does not receive this economy.

#### Catalyst

- **Tracked state:** one active Cue with an exact trigger and eligible ally. The Cue expires or is consumed; cues do not accumulate into a generic currency.
- **Ordinary turn:** establish a Cue through the class action, then an allied actor satisfies its visible trigger to fire a bounded movement, defense shift, condition change, or other authored rider. Tactics changes position and reactions; Resonance changes morale, recovery, and conditions.
- **Progression:** adds cue shapes, eligible triggers, and branch riders. Leadership checks can coordinate ordinary allies but cannot create class Cues or bonus Main actions.
- **Floor and gate:** the campaign must guarantee at least one allied actor in ordinary play. A weak self-cue would merely disguise an Adept/Opportunist loop, so a solo campaign does not offer Catalyst.

#### Rider

- **Tracked state:** mount/vehicle hull or endurance, vehicle-scale position, occupants, and one shared action budget.
- **Ordinary turn:** choose maneuver, attack, passenger support, or damage control while the vehicle changes what Engaged/Near/Far and hazards mean. Ace wins pursuit and firing position; Cavalier controls close approaches and protects passengers.
- **Progression:** unlocks maneuvers and a bonded/assigned vehicle track, not wealth-tier purchases.
- **Floor and gate:** campaign creation guarantees vehicle-capable scenes and a fallback vehicle after loss. Otherwise Pilot remains a skill and the vehicle an asset; Rider is illegal rather than useless in a dungeon crawl.

### 4.1 What the matrix does and does not prove

The matrix proves that authored genre-class packages can be named without turning jobs or status into archetypes. It does **not** prove numerical balance, universal fictional fit, or that every row deserves release.

Three readings are deliberately allowed:

- An **Arcanist Necromancer** performs prepared death rites and may have no minion body. A **Bonded Necromancer** spends the shared action economy through undead companions. The same fiction supports two mechanically honest characters.
- An **Oathbound Paladin** can buy Leadership and hold officer standing without becoming Catalyst. Only a Paladin whose progression also buys the Cue loop multiclasses into Catalyst.
- A **Netrunner** can be opulent and own a corporation. Wealth changes means, Duties, and assets; it does not change Access/Alert or class progression.

Strictly mundane campaigns are a genuine boundary, not a naming exercise. A catalog that forbids supernatural or super-science effects must omit incompatible genre classes at creation. A later portability move cannot make an existing Wizard mundane merely by calling spells “protocols”; that ontology problem remains outside this roster audit.

## 5. Same mechanic, authored genre wording

The help panel should lead with what the class actually does, using the chosen genre class's nouns. The invariant operation stays machine-identical; the UI never says “this is really generic Power with a themed name.” These examples show the required depth of rewriting, not merely a noun substitution.

| Archetype | High-fantasy help example | Cyberpunk help example | Space-opera help example |
|---|---|---|---|
| **Armsmaster** | **Fighter:** “At the start of your turn, adopt one weapon Form. Its strike rider and readied Counter replace your previous Form.” | **Street Samurai:** “Load one combat routine at the start of your turn. Its attack protocol and armed countermeasure replace the last routine.” | **War Adept:** “Adopt one battle pattern. Its firing rider and intercept remain active until you choose another pattern.” |
| **Berserker** | **Barbarian:** “Raise Exposure to drive the attack harder. | **Adept** | **Monk:** “Use an opener, follow its exit stance into a Flow technique, then finish the chain. | **Arcanist** | **Wizard:** “Prepare a limited set of immediate spells from your learned book. ## 7. Established-system precedents to study

No text or named mechanic below is adopted by this audit. It records where a final package can borrow a tested structure instead of inventing one, subject to the licensing ledger already required by `rules-system-variants.md`.

| Design problem | Established precedent worth testing | Candidate use |
|---|---|---|
| Commitment versus expenditure | *Worlds Without Number* / *Cities Without Number* Effort and System Strain | Arcanist/Channeler limited abilities without a generic all-class Power pool |
| Protected-system intrusion | *Cities Without Number* Access/Alert and program structure | Intruder's conditional subsystem |
| Prepared breadth versus spontaneous repertoire | SRD 5.2.1 prepared and known casting structures | Arcanist/Channeler separation |
| Ranked permission and explicit scaling | SRD 5.2.1 spell rank/slot and printed higher-slot effects | All ranked catalog effects; no arbitrary point pouring |
| Form-chain martial play | Open form-chain implementations such as the *13th Age* monk family | Adept opener → flow → finisher test |
| Conditional martial maneuvers | *13th Age* fighter flexible attacks and rogue momentum family | Armsmaster and Opportunist comparison tests |
| Encounter cadence without a pool | *13th Age* at-will, recharge, once-battle, and escalation structures | Cadence-package versions of class abilities |

## 8. Failure map against the frozen nine

### 8.1 Missing homes

| Out-of-sample concept | What the nine-row roster currently forces | Why that is not honest | Candidate correction |
|---|---|---|---|
| Monk, combo fighter, stance-sequence martial | Armsmaster Discipline | Selecting any Form each turn is a different decision from earning a legal finisher through ordered techniques | Admit Adept if the chain survives the collapse test |
| Pet ranger, familiar master, Pokémon-style trainer | Maker Companion or Armsmaster Pursuit plus an asset | A beast, spirit, sidekick, or demon is not necessarily constructed; an ordinary asset has no shared action/progression chassis | Add Bonded; remove the action-taking companion branch from Maker |
| Summoner and minion-centered necromancer | Channeler Manifestation, Arcanist Ritual, or Maker Companion | A one-off effect, ritual, and persistent second body have different action economies | Bonded—Caller for companion play; keep non-companion necromancers in Arcanist |
| Bard or warlord whose actual turn is enabling allies | Opportunist Mastery, Channeler, or the zero-mechanic “commander” role | Expertise, spell use, and holding authority do not produce ally-trigger gameplay | Test conditional Catalyst; keep ordinary bards/commanders in other builds |
| Dedicated vehicle/mech ace | Pilot skill plus asset | That is correct for ordinary pilots, but it cannot express a campaign whose main tactical layer is vehicle hull, vector, and maneuvers | Rider campaign module, never universal roster row |

### 8.2 Collisions and collapse conditions

| Pair | Meaningful difference | Collapse rule |
|---|---|---|
| Armsmaster vs Adept | Free choice of one turn Form/counter versus ordered opener/flow/finisher chain | If random technique order produces materially the same legal effects, fold Adept into Armsmaster |
| Opportunist vs Intruder | One setup/payoff on a target versus persistent multi-node permissions under rising lockdown | If a protected system can be resolved as one Opening plus Systems/Stealth without losing decisions, remove Intruder as a class |
| Arcanist vs Channeler | Broad catalog constrained by preparation versus narrow repertoire constrained by overreach/recovery | If both see the same catalog at the same time and differ only in resource name, merge them |
| Maker vs Bonded | Devices/installations never take a separate turn versus a persistent second body under a shared action budget | Any action-taking construct belongs to Bonded; Maker keeps only non-actor devices |
| Oathbound vs Catalyst | Exact target/zone binding that keys marks/intercepts versus a Cue resolved by another actor | If Catalyst cues are only Leadership boons, delete Catalyst; if Oathbound bindings do not constrain legal targets, ranges, or triggers, reduce them to abilities/role |
| Shifter vs Adept or Maker | Complete profile replacement versus technique sequence or equipment/module management | If a “form” changes only one attack or item, route it out of Shifter |
| Rider vs Pilot/assets | Vehicle-scale action and position system versus ordinary learned operation and ownership | Without guaranteed vehicle scenes and replacement access, delete Rider from that catalog |

## 9. Balance shape before numbers

The roster is not balanced because it has equal row count or equal damage. It is balanceable only if every advantage pays through the same action/effect budget and no candidate receives an extra actor, asset, or unrestricted permission for free.

### 9.1 Required common accounting

1. Every always-available Main is worth one Standard attack or one cataloged non-damage equivalent.
2. Heavy harm, multiple targets, Main-action denial, persistent scene effects, and extra reactions require setup, risk, rank, or the selected variant's limited cadence.
3. A companion, vehicle, installation, summon, follower, or cue never creates an unrestricted extra Main action.
4. Replacement mechanics do not stack: one Shifter profile, one Armsmaster Form, one Adept chain state, one Oathbound declaration, and one Catalyst Cue.
5. Common skills can attempt common tasks. A class buys repeatable exception structure, not ownership of “investigate,” “heal,” “lead,” “pilot,” or “craft.”
6. Wealth and assets expand fictional reach but carry availability/location/obligation limits and never add class-resource capacity.

### 9.2 Cross-pillar target, not equality

| Candidate | Conflict | Exploration / problem solving | Social / world | Deliberate weakness or dependency |
|---|---|---|---|---|
| Armsmaster | High | Medium | Low | few inherent social permissions |
| Berserker | High | Medium | Low | risk is real; subtle control is weak |
| Adept | High | Medium | Medium | finishers require sequence; disruption matters |
| Opportunist | Medium-high | High | High | strongest payoff must be rebuilt after each exploit |
| Intruder* | Medium | High in supported scenes | Medium | deep loop unavailable without protected systems |
| Arcanist | Medium burst | High | Medium | immediate breadth fixed by preparation |
| Channeler | Medium support/burst | Medium | High | narrow repertoire and costly overreach |
| Oathbound | High | Medium | Medium | declaration constrains target and behavior |
| Shifter | High | High | Low-medium | one profile at a time; switching has a cost |
| Maker | Medium | High | Medium | bounded loadout and active-installation cap |
| Bonded | High | High | Medium | one shared Main and two bodies to position/protect |
| Catalyst* | Medium support | Medium | High | allied actor required; cue must be set and triggered |
| Rider† | High in vehicle scenes | High in travel/chases | Low | module and vehicle access required |

### 9.3 Minimum scenario suite

Before any of the three rules variants can claim a balanced roster, equal-level builds need to be run through the same authored fixtures:

- plain four-round fight with no special setup;
- mobile fight with cover, hazard, and a protected objective;
- solo escape or capture scene;
- secured complex with physical, social, occult, and technical routes;
- investigation with evidence that cannot be bypassed by one effect;
- negotiation where rank and wealth help fiction but do not replace checks;
- sealed dungeon/interior with no remote assets or full-size vehicle;
- companion/installation area-effect pressure test;
- boss test with bounded control resistance;
- recovery sequence at the exact cadence of each rules variant.

The conditional/module rows are tested only in campaigns that meet their gate, plus one explicit “gate absent” fixture proving the UI would not offer them.

## 10. Result for the three frozen rules variants

The three rules packages remain useful economy hypotheses, but their shared roster cannot be approved as written.

| Finding | Consequence |
|---|---|
| Bonded is a missing universal mechanic | Add a shared-action companion chassis to each package; do not disguise it as Maker Companion |
| Adept has a plausible unique sequence loop | Prototype opener/flow/finisher against Armsmaster Forms in each package before deciding whether it remains separate |
| Catalyst is coherent only under a party guarantee | Mark it campaign-conditional and compare Cues against ordinary Leadership; never equate it with command rank |
| Intruder also needs a campaign guarantee | Preserve Access/Alert only where protected systems are promised; otherwise build hackers/spies through Opportunist, Maker, and skills |
| Rider changes scene scale | Keep it out of universal class count; design it only as an opted-in campaign module |
| Maker's Companion branch crosses the actor boundary | Replace that branch with Forge; route all separate-body constructs to Bonded |
| Genre naming cannot cure ontology | Strictly mundane catalogs must omit incompatible effects; portability cannot silently reskin magic into technology |

### Recommended working roster for the next design pass

Use the ten universal candidates as the baseline. Carry Intruder and Catalyst as conditional rows with machine-checkable campaign prerequisites. Carry Rider separately as a campaign module. Regenerate all three packages only after the Armsmaster/Adept, Opportunist/Intruder, and Leadership/Catalyst collapse tests have concrete sample cards and scenario results.

This recommendation is deliberately not “add four rows to the old matrix.” It changes Maker's boundary, class availability, and the meaning of the genre catalog. No package is approved, no current runtime is changed, and no external reviewer is invoked by this audit.
